About

I build simulation tools for race cars. My main project is PicoSim, a vehicle dynamics simulator for Formula Student cars that I am building on my own, developed from the physics core up: tire model, powertrain, suspension, aerodynamics, force-feedback steering, and an autonomous driving stack that runs inside it.

My long-term goal is a simulator that can be trusted for real vehicles: one that calibrates itself from real driving data, gets better as more data comes in, and then designs the vehicle, proposing battery capacity, power, vehicle size and suspension kinematics, and the requirements each component has to meet.

Research Interests

Vehicle dynamics simulation

Tire, powertrain and suspension modeling; numerical accuracy of real-time vehicle models.

Data-driven model calibration

Keeping a simulation consistent with the real vehicle by identifying its parameters from measured data.

Simulation-based vehicle design

Using a calibrated model to size components and derive design requirements automatically.
